# 开发路线图

## 阶段一 需求和硬件验证

- 确定前向与内向相机型号、安装位置和视场角。
- 验证双摄像头同时采集、时间戳和带宽。
- 确定 ARM CPU 与 NPU 的最终组合。
- 冻结首版手势集合、眼动输出和验收指标。

交付物：硬件清单、采集样例、需求基线和风险清单。

## 阶段二 数据与教师基线

- 建立数据采集协议、同意书和匿名编号规则。
- 实现手部和眼部 MediaPipe 教师推理。
- 建立伪标签质量检查、可视化和人工复核流程。
- 形成按受试者隔离的数据集版本。

交付物：数据清单、教师基线结果和标注质量报告。

## 阶段三 轻量学生模型

- 建立手部学生模型基线。
- 建立眼部学生模型基线。
- 比较硬标签、软标签和时序一致性蒸馏。
- 完成误差分析和困难场景补采。

交付物：浮点学生模型、模型卡和精度对比。

## 阶段四 量化和端侧运行

- 导出浮点模型并验证数值一致性。
- 使用代表性校准集完成 INT8 量化。
- 接入 CPU 后端和可选 NPU 后端。
- 实现最新帧队列、ROI 跟踪和动态调度。

交付物：离线发布包、INT8 模型和设备基准结果。

## 阶段五 交互融合和系统优化

- 实现眼动聚焦与捏合确认。
- 完成防抖、滞回、重复触发抑制和故障降级。
- 优化端到端延迟、功耗、温度与稳定性。
- 完成至少一次长时间连续运行测试。

交付物：完整演示、事件日志和优化前后对比。

## 阶段六 论文和答辩材料

- 固化可复现实验表格和图表。
- 整理系统框图、硬件照片和演示视频。
- 总结精度、速度、功耗之间的权衡与限制。
- 检查第三方模型、数据和代码的许可证与引用。

交付物：论文实验章节、答辩演示和项目归档包。

## 主要风险

| 风险 | 影响 | 预案 |
| --- | --- | --- |
| 内向相机画面反光或遮挡 | 眼动精度下降 | 调整安装角度，评估近红外方案，增加困难样本 |
| MediaPipe 伪标签偏差 | 学生复制教师错误 | 置信度过滤、人工抽检、少量真值标注 |
| 双路推理算力不足 | 延迟和功耗升高 | 降分辨率、错峰推理、共享调度、NPU 加速 |
| INT8 精度明显下降 | 无法满足交互要求 | 改善校准集、量化感知训练、保留混合精度 |
| 相邻帧泄漏到测试集 | 指标虚高 | 严格按受试者和采集会话划分 |
| 长时间运行热降频 | 性能不稳定 | 主动散热、功耗状态机、持续运行测试 |
