# 数据与知识蒸馏方案

## MediaPipe 的定位

MediaPipe 在本项目中主要作为教师模型、自动标注器和基线系统。最终毕业设计应展示自有的训练流程和轻量学生模型，而不是仅封装 MediaPipe API。

手部教师可使用 Hand Landmarker；眼部教师可从 Face Landmarker 的眼周相关关键点和面部姿态信息构造监督信号。若教师输出不能直接代表真实注视点，还需要标定目标或人工标注，不能把眼周关键点等同于注视真值。

## 数据来源

- 自采第一视角手部视频：不同佩戴者、光照、背景、距离、速度和遮挡。
- 自采近眼视频：不同眼型、眼镜反光、头部姿态、光照和眨眼状态。
- 校准序列：受试者按顺序注视已知目标点，用于建立注视真值。
- 可合法使用的公开数据集：使用前记录许可证、用途限制和引用方式。

## 数据目录约定

```text
data-local/
├─ raw/            # 原始采集，只读保存
├─ teacher/        # MediaPipe 原始教师输出
├─ reviewed/       # 自动过滤和人工复核后的标签
├─ processed/      # 裁剪、归一化后的训练输入
├─ splits/         # 按受试者划分的数据清单
└─ manifests/      # 数据版本、来源、许可和校验信息
```

`data-local/` 只代表本地或受控存储位置，不应提交到 Git。

## 伪标签流程

1. 固定教师模型版本、运行模式和阈值。
2. 对原始视频逐帧运行教师推理，保存坐标、置信度和时间戳。
3. 检查越界点、低置信度、左右翻转、遮挡和时序突变。
4. 对低质量区间进行人工复核，保留“无效”标签而不是强行补值。
5. 以受试者为单位划分训练、验证和测试集。
6. 生成不可变的数据版本清单和统计报告。

## 蒸馏目标

学生模型可以组合以下监督信号：

- 硬标签：人工确认的手势类别、眨眼状态和注视目标。
- 软标签：教师输出的类别概率或置信度分布。
- 几何标签：手部和眼周关键点、ROI、注视方向。
- 特征蒸馏：让学生中间特征接近教师的压缩表示。
- 时序一致性：约束相邻帧输出平滑，同时保留真实快速动作。

首版建议先做输出层蒸馏和伪标签训练，再评估是否需要中间特征蒸馏。这样更容易解释实验变量，也降低教师和学生结构不一致带来的实现复杂度。

## 数据质量门槛

- 训练和测试不能共享同一受试者的相邻视频片段。
- 每个类别统计人数、片段数、帧数和有效标签比例。
- 单一受试者或单一环境不能占据绝大多数样本。
- 保留困难样本集：强反光、低光、快速运动、遮挡、离轴视角。
- 教师失败样本必须纳入误差分析，不能只删除后报告理想指标。

## 版本记录

每个数据版本至少记录：

- 数据来源和采集日期范围
- 受试者数量与匿名编号
- 设备和相机参数
- 教师模型版本与配置
- 清洗规则和人工复核比例
- 训练、验证、测试划分文件
- 删除和保留策略
