# 需求与范围

## 项目目标

构建一套能在 AI 眼镜原型上离线运行的多模态视觉交互系统。系统使用前向相机识别第一视角手势，使用内向相机追踪佩戴者眼部，并在端侧将两类输入融合为稳定的交互事件。

## 必须实现

### 手势识别

- 单手存在检测与 ROI 跟踪。
- 静态手势：张掌、握拳、食指指向、捏合。
- 动态事件：单击、双击、拖动。
- 无手、遮挡或低置信度时不产生误操作。
- 检测与跟踪分工，避免每帧执行完整检测。

### 眼部追踪

- 检测并持续跟踪左眼和右眼区域。
- 输出眼睛开闭或眨眼状态。
- 输出注视方向；完成标定后可进一步输出屏幕或视野中的注视点。
- 头部运动、眼睛短时遮挡或跟踪丢失时能够降级并恢复。
- 未完成用户标定时，不把未经校准的方向结果描述为精确注视点。

### 训练与蒸馏

- 使用 MediaPipe Hand Landmarker 和 Face Landmarker 作为教师或自动标注器。
- 保存教师版本、阈值、输入预处理和标签置信度，确保伪标签可追溯。
- 对低置信度、严重遮挡、越界和时序跳变样本进行过滤或人工复核。
- 训练至少一个可独立部署的轻量学生模型，并与教师基线比较。
- 比较浮点、量化和蒸馏后的精度、体积、延迟和能耗。

### 端侧运行

- 断网后仍可完成摄像头采集、推理和事件输出。
- 运行时不依赖云端 API 或按需下载模型。
- 支持 CPU 基线，条件允许时支持 NPU 加速。
- 支持待机、跟踪、交互三个功耗状态及带滞回的状态切换。
- 推理队列必须有上限，优先丢弃过期帧，不能积压视频造成高延迟。

## 建议实现

- 眼动聚焦加捏合确认的组合交互。
- 用户级眼动标定与标定质量评分。
- 手势和眼动模型共享部分轻量视觉骨干的对比实验。
- 端侧模型热切换和故障回退。
- 佩戴者个体适配，但不上传个人眼部数据。

## 暂不纳入首版

- 大规模开放词汇手势识别。
- 云端推理作为核心链路。
- 医疗级眼动诊断。
- 高精度空间定位或完整 SLAM。
- 以人脸身份识别为目的的功能。

## 初始验收口径

最终阈值应在硬件和数据试验后锁定，首轮至少满足：

- 设备断网后可完整启动并持续输出手势与眼动结果。
- 两路视频均使用真实眼镜视角采集，而非只在公开数据集上离线测试。
- 报告准确率之外，还包含 P50、P95、P99 延迟、帧间隔波动、内存、温度、平均功率和单位事件能耗。
- 至少进行教师模型、学生浮点模型和学生 INT8 模型三组对比。
- 连续运行测试中无未受控队列增长、崩溃或明显热降频失控。

## 隐私与伦理

- 采集前取得受试者知情同意，说明用途、保存周期和删除方式。
- 眼部和面部图像视为敏感数据，默认不上传、不公开、不长期保留。
- 数据集划分以受试者为单位，避免同一人的相邻帧同时进入训练集和测试集。
- 演示和论文展示优先使用匿名化图像、关键点或统计结果。
