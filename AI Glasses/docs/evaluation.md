# 评测方案

## 评测原则

所有最终结论都应来自真实端侧设备。开发机结果可用于调试和算法对比，但不能替代端侧延迟、功耗和温升测量。

## 手势指标

- 手部存在检测的精确率、召回率和 F1。
- 关键点 PCK 或归一化误差。
- 静态手势准确率、宏平均 F1 和混淆矩阵。
- 单击、双击、拖动等事件级精确率、召回率和重复触发率。
- 遮挡、低光、运动模糊和不同背景下的分组表现。

## 眼部指标

- 眼部 ROI 跟踪成功率和丢失后恢复时间。
- 眼周关键点的归一化误差。
- 注视方向角误差。
- 标定后注视点误差，按实际显示距离使用角度或像素报告。
- 眨眼检测的精确率、召回率和 F1。
- 不同受试者、眼镜反光、头部姿态和光照下的分组表现。

## 系统指标

- 摄像头输入到交互事件输出的端到端延迟。
- P50、P95 和 P99 延迟。
- 连续帧间隔标准差或其他抖动指标。
- 实际处理 FPS、输入丢帧率和过期帧丢弃率。
- 峰值与稳定内存占用。
- CPU、NPU 使用率和数据搬运时间。
- 平均功率、峰值功率、单位有效事件能耗。
- 连续运行中的温度、频率和热降频情况。

## 必做对比

| 组别 | 用途 |
| --- | --- |
| MediaPipe 教师 | 精度上限和伪标签来源 |
| 学生浮点模型 | 证明轻量结构本身的效果 |
| 学生蒸馏模型 | 量化蒸馏带来的精度收益 |
| 学生 INT8 模型 | 端侧最终候选 |
| CPU 与 NPU | 软硬协同收益 |
| 固定帧率与动态调度 | 功耗和延迟权衡 |

## 测试集划分

- 训练、验证和测试按受试者隔离。
- 另设困难场景集，不参与阈值调节。
- 另设连续运行集，用于观察温升、内存和队列稳定性。
- 对相同视频回放不同模型，保证输入一致。

## 实验记录

每次实验至少记录：

- 代码版本和配置版本
- 数据集与划分版本
- 模型文件哈希
- 设备、系统、运行时和加速器版本
- 相机分辨率、帧率和曝光设置
- 预热时间、测试时长和重复次数
- 汇总指标与原始日志位置
- 异常、失败样本和已知限制
