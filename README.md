# AI-Glasses
Ultra-lightweight and low-power gesture recognition algorithm for AI glasses and end-side hardware-software collaborative design
--- 每次开始工作前 ---
1. 切换到 main 分支：git switch main
2. 拉取最新代码：git pull
3. 创建自己的功能分支：git switch -c feature/你的名字-任务简述

--- 写代码并提交 ---
1. 查看修改状态：git status
2. 添加所有修改：git add .
3. 提交：git commit -m "写清楚你做了什么"
4. 推送到 GitHub：git push -u origin feature/你的名字-任务简述

--- 发起 Pull Request ---
1. 打开 GitHub 仓库页面
2. 点击 Compare & pull request
3. 填写 PR 标题和描述
4. 在 Reviewers 里选择组长
5. 点击 Create pull request

--- 等待审查与合并 ---
1. 组长在 PR 里 review 代码
2. 根据意见修改后重新提交并推送
3. 组长确认无误后点击 Merge

--- 合并后清理 ---
1. 切换回 main：git switch main
2. 拉取最新代码：git pull
3. 删除本地分支：git branch -d feature/你的名字-任务简述
